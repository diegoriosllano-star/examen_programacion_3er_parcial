## Descripción

Proyecto correspondiente al tercer examen parcial de Programación II.

El proyecto incluye ejercicios de programación orientada a objetos utilizando clases, propiedades, métodos, `__init__`, `self`, creación de objetos y herencia simple.

Se desarrollaron las siguientes actividades:

- Interpretación de elementos de programación orientada a objetos.
- Clase `Rectangulo` para calcular y mostrar un área.
- Interpretación de herencia mediante las clases `Operacion` y `Multiplicacion`.
- Clase `Estacionamiento` para calcular el cobro según las horas registradas.
- Calculadora con herencia utilizando las clases `Operacion` y `Resta`.

## Ejecución

Para ejecutar la Parte 1:

```
python examen/preguntas.py
```

Para ejecutar el ejercicio de estacionamiento:

```
python ejercicio_1/main.py
```

Para ejecutar la calculadora con herencia:

```
python ejercicio_2/main.py
```
